Birthday Surprise Website
==========================

Open index.html in a browser.

To personalize:
1. Replace the placeholder memory/photo area with your photos.
2. Edit the 6 wishes in script.js.
3. Edit the birthday letter in index.html.
4. Edit the final scratch-card message in index.html.
5. You can change colors/text in style.css.

No paid service is required to run this locally.
